FloWW can now update itself.

> Coming from 0.1.0 or 0.1.1? Those versions have no update button yet, so install 0.1.2 by hand
> once (commands below). From then on, use **Check for updates**.

## What changed

- **Check for updates** at the bottom of the sidebar (also on the first screen). It asks GitHub for
  the latest release. If you already have it, it says so. If not, it shows the new version, what
  happens next, and which old installer files will be deleted.
- **Desktop app:** FloWW closes, a small window shows the progress (download, check the file,
  install, remove old files), then the new version opens. The .deb asks for your password through
  the system prompt; the AppImage replaces itself.
- **Web UI (floww-web):** progress shows in the page; FloWW restarts on the same port with the same
  link and the page reloads.
- Every download is checked against `SHA256SUMS.txt`. If it does not match, nothing is installed.
- Your settings (`~/.config/floww`), workspaces and brain stay. Only FloWW's own old release files
  are removed (`FloWW_*.deb`, `FloWW_*.AppImage`, `floww-web-v*` tarballs and folders older than the
  new version) from `~/Downloads`, `~/Unduhan` and the folder FloWW runs from.

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.2/FloWW_0.1.2_amd64.deb
sudo apt install ./FloWW_0.1.2_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.2/FloWW_0.1.2_amd64.AppImage
chmod +x FloWW_0.1.2_amd64.AppImage && ./FloWW_0.1.2_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.2/floww-web-v0.1.2-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.2-linux-x86_64.tar.gz
./floww-web-v0.1.2-linux-x86_64/floww-web --open
```

## Bahasa Indonesia

Sekarang ada tombol **Check for updates** di bawah sidebar. Kalau ada versi baru: aplikasi
desktop menutup, jendela kecil menampilkan progres (unduh → cek file → pasang → hapus file lama),
lalu versi baru terbuka sendiri. Versi web restart sendiri dan halaman dimuat ulang. Data
(pengaturan, workspace, brain) tetap aman; yang dihapus hanya file installer FloWW lama. Kalau
tidak ada versi baru, muncul "You have the latest version".

Dari 0.1.0/0.1.1 pasang 0.1.2 secara manual sekali dulu; setelah itu cukup pakai tombolnya.
