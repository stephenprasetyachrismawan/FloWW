Faster building: one Claude Code session per request, no loop.

Already on 0.1.2 or newer? Press **Check for updates** at the bottom of the sidebar.

## What changed

- **Building is one session.** Claude Code gets the whole PRD as the spec plus all acceptance
  criteria, works test-first, and runs the module tests itself. Before, FloWW started a new session
  for every criterion, ran the Odoo tests again after each one, and retried up to 5 times.
- **No automatic retries.** If the tests still fail at the end, the card shows **Help the AI** with
  what fails. Your hint continues the same session, so Claude Code remembers everything it did.
  Feedback from your Odoo test also continues that session.
- **Less added on top of Claude Code.** Removed: the "AI tries before asking you" setting, the
  per-criterion test runs, the edit-check hook and the progress file in the worktree. FloWW still
  writes a short `CLAUDE.local.md` with the Odoo test and upgrade commands and your team's
  conventions, because Claude Code cannot know those.
- The build session may run up to 60 minutes (was 30 per criterion).

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.4/FloWW_0.1.4_amd64.deb
sudo apt install ./FloWW_0.1.4_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.4/FloWW_0.1.4_amd64.AppImage
chmod +x FloWW_0.1.4_amd64.AppImage && ./FloWW_0.1.4_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.4/floww-web-v0.1.4-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.4-linux-x86_64.tar.gz
./floww-web-v0.1.4-linux-x86_64/floww-web --open
```
