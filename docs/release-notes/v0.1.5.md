Effort setting, and old failing tests no longer block a build.

Press **Check for updates** at the bottom of the sidebar to get it.

## What changed

- **Effort** in Settings (with the AI model): Low, Medium, High, Extra high, Max, or Claude Code's
  default. **Effort for building** can differ, for example Low for questions and commit messages
  and High for building. FloWW passes it to Claude Code as `--effort`; leave it on the default and
  nothing changes.
- **Tests that already failed before your change are ignored.** The build session now leaves them
  alone and only counts its new or changed tests and tests that passed before. So a module with
  old broken tests no longer ends in "The tests still fail".

A request that is already stuck on "The tests still fail" because of old tests: press
**Give a hint**, write "ignore tests that already failed before", and continue. It resumes the
same session.

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.5/FloWW_0.1.5_amd64.deb
sudo apt install ./FloWW_0.1.5_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.5/FloWW_0.1.5_amd64.AppImage
chmod +x FloWW_0.1.5_amd64.AppImage && ./FloWW_0.1.5_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.5/floww-web-v0.1.5-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.5-linux-x86_64.tar.gz
./floww-web-v0.1.5-linux-x86_64/floww-web --open
```
