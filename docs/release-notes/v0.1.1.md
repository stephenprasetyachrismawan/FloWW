Fixes adding a workspace. Install and run exactly as in
[v0.1.0](https://github.com/stephenprasetyachrismawan/FloWW/releases/tag/v0.1.0), with the new file
names below.

## What changed

- **Choose folder…** in Add workspace. The desktop app opens your system's folder picker. The
  web UI opens a folder browser that marks git repositories, so you no longer type paths.
- **Clear errors for paths.** Instead of "is not a folder", FloWW now says what is wrong and how to
  fix it:
  - the folder does not exist on the computer running FloWW, with the closest name
    ("Did you mean …/IndoCasa?", one click to use it) or the folders that are there;
  - FloWW's user is not allowed to open it, which folder blocks it, and the `chmod` to fix it;
  - it is a file, or not a full path.
- Pasted paths are cleaned up: spaces, quotes, a trailing `/`, `~/…` and `file://` all work.
- Choosing a folder inside a repository uses the repository's top folder.

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.1/FloWW_0.1.1_amd64.deb
sudo apt install ./FloWW_0.1.1_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.1/FloWW_0.1.1_amd64.AppImage
chmod +x FloWW_0.1.1_amd64.AppImage && ./FloWW_0.1.1_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.1/floww-web-v0.1.1-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.1-linux-x86_64.tar.gz
./floww-web-v0.1.1-linux-x86_64/floww-web --open
```

Upgrading the .deb: install the new file the same way; your settings in `~/.config/floww` stay.

## Bahasa Indonesia
