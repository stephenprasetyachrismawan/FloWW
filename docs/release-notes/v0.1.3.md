Choose your development branch and how new branches are named.

Already on 0.1.2? Press **Check for updates** at the bottom of the sidebar.

## What changed

- **Development branch** (Add workspace and Settings): the branch new work starts from and pull
  requests go to, for example `preprod` or `development`. If it does not exist yet, FloWW creates
  it from the default branch.
- **New branch names**: a template with a live example as you type. The default is now
  `dev/{ddmmyyyy}_{slug}`, which gives names like `dev/28102026_invoice-dobel-saat`.
  - Tokens: `{slug}` (first words of the request title), `{type}` (feature, improvement or bugfix),
    `{prd_id}`, `{ddmmyyyy}`, `{yyyymmdd}`, `{dd}`, `{mm}`, `{yyyy}`.
  - The date is the day the request was made, so the name stays the same if work continues on
    another day.
  - Unknown tokens, a missing `{slug}`/`{prd_id}`, or characters git does not allow are caught or
    cleaned up before anything is created.
- Update checks and GitHub calls now also trust your system's certificates, so they work behind
  office networks that inspect HTTPS. If **Check for updates** in 0.1.2 says it cannot reach
  GitHub on such a network, install 0.1.3 by hand once.
- Both are team settings: they live in the shared brain and changes are recorded with your name.
  Workspaces that already have a branch name saved keep it; change it in Settings.

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.3/FloWW_0.1.3_amd64.deb
sudo apt install ./FloWW_0.1.3_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.3/FloWW_0.1.3_amd64.AppImage
chmod +x FloWW_0.1.3_amd64.AppImage && ./FloWW_0.1.3_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.3/floww-web-v0.1.3-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.3-linux-x86_64.tar.gz
./floww-web-v0.1.3-linux-x86_64/floww-web --open
```

## Bahasa Indonesia

Di **Add workspace** dan **Settings** sekarang bisa diatur:

- **Development branch**: branch asal kerja baru dan tujuan PR (misalnya `preprod`).
- **New branch names**: pola nama branch, default `dev/{ddmmyyyy}_{slug}`, contohnya
  `dev/28102026_invoice-dobel-saat`. Contoh nama langsung tampil saat Anda mengetik.

Dari 0.1.2 cukup klik **Check for updates**.
