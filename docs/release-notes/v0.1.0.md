First release of FloWW (phase 1): a request goes through grill-me, PRD, branch, AI coding with
TDD, local Odoo testing, your feedback, and commit/push/PR. The team's shared brain is an Obsidian
vault on the `floww/brain` branch.

Linux x86_64 only for now. Pick **one** of the three downloads below.

## Before you install

FloWW drives tools that are already on your machine:

| Needed | Install |
|---|---|
| Claude Code CLI, signed in | `npm install -g @anthropic-ai/claude-code` then `claude login` (or use a 9router address and key in the first screen) |
| git, Python 3 | `sudo apt install git python3` |
| Optional: read the local Odoo database | `sudo apt install postgresql-client` |
| Optional: keep tokens in the system keyring | `sudo apt install libsecret-tools` |
| Optional: open pull requests | `gh auth login`, or a GitHub token in Settings |

## Option 1: desktop app (.deb, Ubuntu/Debian)

```sh
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.0/FloWW_0.1.0_amd64.deb
sudo apt install ./FloWW_0.1.0_amd64.deb
```

Start it from the app menu (**FloWW**) or from a terminal:

```sh
floww
```

Remove it with `sudo apt remove floww`.

## Option 2: desktop app (AppImage, any distro)

```sh
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.0/FloWW_0.1.0_amd64.AppImage
chmod +x FloWW_0.1.0_amd64.AppImage
./FloWW_0.1.0_amd64.AppImage
```

If it says FUSE is missing: `sudo apt install libfuse2t64` (Ubuntu 24.04) or `libfuse2` (older).

## Option 3: web UI in your browser (floww-web)

No desktop libraries needed. Good for a dev server or WSL.

```sh
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.0/floww-web-v0.1.0-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.0-linux-x86_64.tar.gz
cd floww-web-v0.1.0-linux-x86_64
./floww-web --open
```

It prints a link like `http://127.0.0.1:7171/?token=…`; `--open` opens it in your browser. The
token is new each start and gives full access, so keep the link private. Stop with Ctrl+C.

Options: `--port 8080` uses another port, `--token <value>` keeps the same link across restarts,
`FLOWW_HOME=/path` uses another config folder (default `~/.config/floww`). To call it from
anywhere, copy it onto your PATH:

```sh
install -Dm755 floww-web ~/.local/bin/floww-web
floww-web --port 7171
```

The server only listens on 127.0.0.1. From another machine, use an SSH tunnel:
`ssh -L 7171:127.0.0.1:7171 your-server`, then open the printed link on your machine.

## First run

1. Choose **My Claude subscription** (uses `claude login`) or **9router** (address without `/v1`
   and its API key, saved in the keyring).
2. Pick the default model and press **Send a test message** to check it works.
3. **Add workspace**: point it at your Odoo repo. FloWW reads `.vscode/launch.json` for the Odoo
   command, and you set the base branch (for example `preprod`) and the local database.
4. **New request** and follow the board.

Check the downloads with `sha256sum -c SHA256SUMS.txt --ignore-missing`.

## Cara cepat (Bahasa Indonesia)

- **Desktop (.deb):** `sudo apt install ./FloWW_0.1.0_amd64.deb`, lalu buka **FloWW** dari menu
  aplikasi atau ketik `floww` di terminal.

  buka link `http://127.0.0.1:7171/?token=…` yang dicetak. Jangan bagikan link itu.
- Wajib ada Claude Code CLI yang sudah `claude login` (atau 9router), git, dan Python 3.
