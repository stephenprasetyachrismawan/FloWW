Chat with Claude Code on every request, Odoo runs from the right worktree, delete requests.

Press **Check for updates** at the bottom of the sidebar to get it.

## What changed

- **Now is a chat**, like the Claude Code extension in VS Code: what FloWW asked, Claude's replies
  (Markdown, code colored), and each step it takes (read, edit, run). Type in the box at the bottom
  any time:
  - while Claude works, it stops and continues **the same session** with your message;
  - while testing, Odoo stops, Claude works on your message, and the request comes back to testing;
  - the square button stops the AI.
- **Fixed: upgrades and tests ran the main checkout instead of the request's worktree.** Each
  request now gets its own temporary `launch.json` (and Odoo config copy) in
  `.floww/tasks/<id>/`, with every path pointing at its worktree and `--addons-path` starting with
  the worktree's module folders. Removed when the request is done or deleted.
- **Requests share the local database** (Settings → "Requests share the local database", on by
  default). Each request runs Odoo on its own port: the workspace port, then the next free one.
- **Delete a request** (top right of the request page). Stops its AI and Odoo, removes its worktree,
  local branch and conversation. Brain notes and anything pushed stay.
- **Appearance** in Settings: text size (Small to Extra large) and font (Sans, Serif, System).

## Install

```sh
# Desktop, Ubuntu/Debian
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.6/FloWW_0.1.6_amd64.deb
sudo apt install ./FloWW_0.1.6_amd64.deb      # then run: floww

# Desktop, any distro
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.6/FloWW_0.1.6_amd64.AppImage
chmod +x FloWW_0.1.6_amd64.AppImage && ./FloWW_0.1.6_amd64.AppImage

# Web UI
curl -LO https://github.com/stephenprasetyachrismawan/FloWW/releases/download/v0.1.6/floww-web-v0.1.6-linux-x86_64.tar.gz
tar xzf floww-web-v0.1.6-linux-x86_64.tar.gz
./floww-web-v0.1.6-linux-x86_64/floww-web --open
```
